# Dashboard design system

## Direction

The dashboard is an operational ledger: quiet, severe, and precise. It uses
large negative space, thin ornamental rules, and one blade-like vertical axis.
It must not resemble a generic rounded SaaS card grid.

## Palette

| Token | Value     | Use                                  |
| ----- | --------- | ------------------------------------ |
| Void  | `#050505` | Primary canvas                       |
| Coal  | `#0b0b0b` | Raised work areas                    |
| Bone  | `#f2f2ef` | Primary text                         |
| Ash   | `#a3a3a0` | Secondary text                       |
| Steel | `#2a2a29` | Dividers and inactive controls       |
| Wound | `#7f252b` | Risk, sanctions, destructive actions |

## Type

- `UnifrakturCook`: Latin wordmark only.
- `Cormorant`: Russian display headings.
- `Manrope`: controls, tables, and long-form interface text.

## Accessibility

- Visible keyboard focus is mandatory.
- Information never relies on color alone.
- Motion responds to user action and respects reduced-motion preferences.
- Body line length remains below 80 characters.
